# Password Strength Audit using CrackStation

This project evaluates the strength of common and custom passwords by:

- Generating MD5 hashes for sample passwords
- Using CrackStation to attempt cracking them
- Recording whether they are easily guessable
- Giving recommendations for stronger passwords

## Tools Used
- [CrackStation](https://crackstation.net)
- Linux `md5sum` or online MD5 generator
- Markdown for table formatting
